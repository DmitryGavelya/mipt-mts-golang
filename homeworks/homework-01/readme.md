## Цель задания

Научиться переносить алгоритм с C/Python на идиоматичный Go и
покрывать его табличными тестами — чтобы писать простой код на Go
и обращаться с ошибками как со значениями.

## Ваш результат

В результате выполнения задания вы:

- реализуете функцию `EvalPostfix(tokens []string) (int, error)` в `main.go`;
- добавите обработку деления на ноль через возврат `error` вместо аварийного завершения;
- напишете табличные тесты на успешные и на ошибочные случаи в `main_test.go`;
- пройдёте все тесты — `go test -v` в папке `homework-01`.

## Задача

В статье по ссылке разобран алгоритм вычисления выражения в
постфиксной записи (обратная польская запись) с готовым кодом на C.
Токены выражения приходят уже разбитыми на слайс строк: операнды —
целые числа, операторы — `+`, `-`, `*`, `/`. Нужно перенести
алгоритм на Go по стеку и вернуть результат.

Код на C при делении на ноль падает. В Go так делать нельзя: ошибка
должна быть значением, которое вызывающий код обязан проверить.
Поэтому сигнатура возвращает `(int, error)`, а не просто `int`.

## Что нужно сделать

1. Реализуйте `EvalPostfix(tokens []string) (int, error)` в `main.go` через стек.
2. Для корректного выражения верните результат и `nil`.
3. При делении на ноль верните нулевой результат и ненулевой `error` — без `panic`.
4. Для некорректного выражения (нехватка операндов, неизвестный токен) верните `error`.
5. Напишите в `main_test.go` табличные тесты на успешные случаи, например:

   ```
   ["2","3","+"]            -> 5
   ["5","1","2","+","4","*","+","3","-"] -> 14
   ```

6. Добавьте в ту же таблицу (или отдельной) тесты на ошибки: деление
   на ноль и битое выражение должны возвращать `error`. Тест
   проверяет именно факт `error != nil` — если ошибки нет, тест не
   проходит.
7. Прогоните проверку:

   ```
   go vet ./...
   go test -v
   ```

   Ожидаемый результат: `go vet` молчит, все тесты `PASS`.

## Важные ограничения

- Деление на ноль не должно вызывать `panic` или завершать программу.
- Признак ошибки — значение `error`, а не магическое число (`-1`, `0`) в результате.
- Возвращённый `error` нельзя игнорировать молча — тесты на ошибки обязательны.

## Критерии проверки

Задание принимается, если:

- код собирается, `go vet ./...` без замечаний;
- корректные постфиксные выражения вычисляются верно;
- деление на ноль возвращает `error`, программа не падает;
- некорректное выражение возвращает `error`;
- есть табличные тесты на успешные случаи;
- есть тесты на ошибочные случаи, ожидающие `error`;
- `go test -v` в папке `homework-01` проходит полностью.
